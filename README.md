\# Career Memory



Career Memory is an AI-powered personal career intelligence platform.



The goal is to help professionals understand and organize:



\* Recruiter interactions

\* Job submissions

\* Interview history

\* Assessment requests

\* Hiring outcomes

\* Career timelines



\## Features



\* Gmail ingestion

\* Recruiter interaction classification

\* Career timeline generation

\* Duplicate submission detection

\* Privacy-preserving redaction

\* AI-powered search



\## Example Questions



\* Which recruiters have contacted me most often?

\* Which agencies resulted in interviews?

\* How many times was I submitted to the same client?

\* Which skills generate the most recruiter interest?

\* Show every interaction involving Databricks.

\* Show recruiters who requested an RTR but never followed up.
