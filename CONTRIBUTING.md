\# Contributing to Career Memory



\## Engineering Philosophy



Career Memory is built incrementally using small, reviewable engineering stories.



Every feature should solve a real problem and integrate cleanly into the existing architecture.



\---



\# Branches



Use one feature branch per engineering story.



Examples



feature/gmail-mvp



feature/linkedin-import



feature/entity-extraction



\---



\# Commit Messages



Use the format:



CM-### Short description



Examples



CM-008 Add Gmail client abstraction



CM-009 Implement Gmail connector



CM-010 Add recruiter parser



\---



\# Definition of Done



Every issue must:



\* Compile successfully

\* Pass existing tests

\* Avoid modifying unrelated files

\* Include type hints

\* Include docstrings

\* Preserve project architecture



\---



\# AI-Assisted Development



AI is used for implementation assistance.



Architecture, product direction, code review, and merge decisions remain human responsibilities.



AI-generated code is reviewed before every commit.



\---



\# Project Principles



1\. Privacy first.

2\. Deterministic before AI.

3\. Small commits.

4\. Clean architecture.

5\. One responsibility per module.

6\. Every feature should make Career Memory more useful.
