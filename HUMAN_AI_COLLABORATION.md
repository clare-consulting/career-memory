\# Human + AI Collaboration



\## Philosophy



Career Memory is built using an AI-assisted software engineering workflow.



The objective is not to replace engineering judgment, but to accelerate implementation while maintaining human ownership of product direction, architecture, and code quality.



\---



\# Human Responsibilities



The human developer is responsible for:



\* Product vision

\* Requirements gathering

\* Architecture

\* Data modeling

\* Technology selection

\* Security decisions

\* Privacy decisions

\* Code review

\* Final approval of every change



\---



\# AI Responsibilities



AI assistants are used to accelerate development by helping with:



\* Boilerplate generation

\* Small feature implementation

\* Unit tests

\* Documentation

\* Refactoring suggestions

\* API integration examples

\* Code explanation



All generated code is reviewed before being committed.



\---



\# Development Workflow



1\. Define a feature or GitHub Issue.

2\. Design the architecture.

3\. Use AI to implement a small, well-scoped task.

4\. Review generated code.

5\. Test locally.

6\. Commit changes.

7\. Merge after review.



\---



\# Guiding Principles



\* Human-reviewed code only.

\* No direct commits from AI.

\* Small, reviewable changes.

\* Privacy-first design.

\* Architecture before implementation.

\* Deterministic logic before AI.



\---



\# Why this approach?



Career Memory demonstrates how experienced software engineers can collaborate with AI to build production-quality software while retaining ownership of engineering decisions.
