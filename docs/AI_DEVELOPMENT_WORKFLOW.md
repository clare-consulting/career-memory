\# AI Development Workflow



Career Memory is built using an AI-assisted engineering workflow.



\## Roles



\### Product Owner

Defines product direction, user needs, and priorities.



\### ChatGPT

Supports architecture, data modeling, sprint planning, code review, and product strategy.



\### Codex

Implements small, scoped engineering tasks such as connectors, tests, refactors, and documentation.



\## Workflow



1\. Create an issue or backlog item.

2\. Create a feature branch.

3\. Use Codex for a scoped implementation task.

4\. Review generated code.

5\. Run tests.

6\. Commit changes.

7\. Open a pull request.

8\. Merge after review.



\## Principles



\- Keep changes small.

\- Prefer deterministic logic before AI.

\- Do not commit private email data.

\- Redact sensitive personal information.

\- Document major design decisions.
