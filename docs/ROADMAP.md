\# Career Memory Roadmap



\## Vision



Career Memory is an AI-powered personal career intelligence platform.



The goal is to help professionals organize and analyze their career history across multiple data sources.



Supported data sources will include:



\* Gmail

\* LinkedIn

\* Dice

\* ClearanceJobs

\* Google Calendar

\* Resume versions

\* GitHub

\* Manual notes
